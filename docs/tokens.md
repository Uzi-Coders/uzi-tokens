# توکن‌های API

مدیریت توکن‌های API با سشن واردشده انجام می‌شود. هر کاربر حداکثر **۱۰ توکن** می‌تواند داشته باشد. هر توکن یک سطح دسترسی دارد:

- `read`: فقط خواندن
- `read_write`: خواندن و نوشتن

توکن‌ها با پیشوند `stz_` ساخته می‌شوند. مقدار کامل توکن فقط در پاسخ ساخت و اندپوینت reveal برمی‌گردد.

## مشاهده لیست توکن‌ها

```http
GET /api/uzi-token/tokens/
```

> **نیاز به احراز هویت: بله**

### پاسخ موفقیت (200)

پاسخ یک آرایه از توکن‌هاست.

| توضیحات            | نوع                             | پارامتر        |
|--------------------|---------------------------------|----------------|
| شناسه توکن         | Integer                         | `id`           |
| نام توکن           | String                          | `name`         |
| نسخه ماسک شده توکن | String                          | `masked_token` |
| سطح دسترسی         | String (`read` یا `read_write`) | `permission`   |
| تاریخ ساخت         | String (ISO 8601)               | `created_at`   |

نمونه:

```json
[
  {
    "id": 1,
    "name": "ci-token",
    "masked_token": "stz_AbCd****************WXYZ",
    "permission": "read",
    "created_at": "2026-10-05T12:00:00Z"
  }
]
```

> در لیست، فقط نسخه ماسک شده توکن نمایش داده می‌شود.

## ساخت توکن جدید

```http
POST /api/uzi-token/tokens/
```

> **نیاز به احراز هویت: بله**

### بدنه درخواست

| توضیحات    | اجباری | نوع                                     | پارامتر      |
|------------|--------|-----------------------------------------|--------------|
| نام توکن   | بله    | String (حداکثر ۶۴ کاراکتر)              | `name`       |
| سطح دسترسی | خیر    | `read` یا `read_write` (پیش‌فرض `read`) | `permission` |

نمونه:

```json
{
  "name": "ci-token",
  "permission": "read_write"
}
```

### پاسخ موفقیت (201)

| توضیحات            | نوع                             | پارامتر        |
|--------------------|---------------------------------|----------------|
| شناسه توکن         | Integer                         | `id`           |
| نام توکن           | String                          | `name`         |
| نسخه ماسک شده توکن | String                          | `masked_token` |
| سطح دسترسی         | String (`read` یا `read_write`) | `permission`   |
| تاریخ ساخت         | String (ISO 8601)               | `created_at`   |
| مقدار کامل توکن    | String                          | `token`        |

نمونه:

```json
{
  "id": 1,
  "name": "ci-token",
  "masked_token": "stz_AbCd****************WXYZ",
  "permission": "read_write",
  "created_at": "2026-10-05T12:00:00Z",
  "token": "stz_AbCdEfGh..."
}
```

### نکات

- مقدار کامل توکن در پاسخ ساخت برگردانده می‌شود.
- اگر کاربر ۱۰ توکن داشته باشد، ساخت توکن جدید انجام نمی‌شود.

## نمایش مقدار توکن

```http
POST /api/uzi-token/tokens/<token_id>/reveal/
```

> **نیاز به احراز هویت: بله**

### پاسخ موفقیت (200)

| توضیحات         | نوع    | پارامتر |
|-----------------|--------|---------|
| مقدار کامل توکن | String | `token` |

نمونه:

```json
{
  "token": "stz_AbCdEfGh..."
}
```

## حذف توکن

```http
DELETE /api/uzi-token/tokens/<token_id>/
```

> **نیاز به احراز هویت: بله**

حذف دائمی است و رکورد توکن پاک می‌شود.

### پاسخ موفقیت (204)

بدون بدنه.

## خطاها

| توضیحات                          | کد وضعیت |
|----------------------------------|----------|
| اطلاعات ورودی معتبر نیست.        | 400      |
| سقف ۱۰ توکن پر شده است.          | 400      |
| کاربر وارد حساب کاربری نشده است. | 401      |
| توکن پیدا نشد.                   | 404      |
