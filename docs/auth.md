# احراز هویت (Authentication)

ثبت نام و ورود با **نام کاربری و رمز عبور** انجام می‌شود. پس از ثبت نام یا ورود، یک سشن ایجاد می‌شود و درخواست‌های بعدی با کوکی سشن شناسایی می‌شوند.

نام، نام خانوادگی و ایمیل اختیاری هستند. اگر این فیلدها ارسال نشوند یا مقدار `null` داشته باشند، در پاسخ به صورت `null` برگردانده می‌شوند.

> برای درخواست‌های ناامن (`POST`، `PUT`، `PATCH`، `DELETE`) که با سشن واردشده انجام می‌شوند، هدر `X-CSRFToken` لازم است. توکن CSRF از `GET /api/uzi-token/csrf/` قابل دریافت است.

## ثبت نام (Sign up)

```http
POST /api/uzi-token/auth/signup/
```

> **نیاز به احراز هویت: خیر**

### بدنه درخواست

| توضیحات      | اجباری | نوع            | پارامتر      |
|--------------|--------|----------------|--------------|
| نام کاربری   | بله    | String         | `username`   |
| رمز عبور     | بله    | String         | `password`   |
| نام          | خیر    | String \| null | `first_name` |
| نام خانوادگی | خیر    | String \| null | `last_name`  |
| ایمیل        | خیر    | String \| null | `email`      |

نمونه:

```json
{
  "username": "alializadeh",
  "password": "StrongPassword123",
  "first_name": "علی",
  "last_name": "علیزاده",
  "email": "example@gmail.com"
}
```

نمونه بدون اطلاعات اختیاری:

```json
{
  "username": "alializadeh",
  "password": "StrongPassword123"
}
```

### پاسخ موفقیت (201)

```json
{
  "message": "Account created successfully.",
  "user": {
    "username": "alializadeh",
    "first_name": null,
    "last_name": null,
    "email": null
  }
}
```

### نکات

- بعد از ثبت نام، کاربر به صورت خودکار وارد می‌شود.
- رمز عبور باید حداقل ۶ کاراکتر باشد و رمزهای رایج یا کاملاً عددی پذیرفته نمی‌شوند.
- ایمیل در صورت ارسال باید معتبر باشد.
- ظرفیت تعداد کاربران محدود است؛ وقتی ظرفیت پر شود، ثبت نام جدید انجام نمی‌شود.

### خطاها

| توضیحات                           | کد وضعیت |
|-----------------------------------|----------|
| اطلاعات ورودی معتبر نیست.         | 400      |
| نام کاربری قبلاً استفاده شده است. | 400      |
| رمز عبور ضعیف است.                | 400      |

## ورود (Login)

```http
POST /api/uzi-token/auth/login/
```

> **نیاز به احراز هویت: خیر**

### بدنه درخواست

| توضیحات    | اجباری | نوع    | پارامتر    |
|------------|--------|--------|------------|
| نام کاربری | بله    | String | `username` |
| رمز عبور   | بله    | String | `password` |

نمونه:

```json
{
  "username": "alializadeh",
  "password": "StrongPassword123"
}
```

### پاسخ موفقیت (200)

```json
{
  "message": "Logged in successfully.",
  "user": {
    "username": "alializadeh",
    "first_name": "علی",
    "last_name": "علیزاده",
    "email": "example@gmail.com"
  }
}
```

### خطاها

| توضیحات                            | کد وضعیت |
|------------------------------------|----------|
| اطلاعات ورودی معتبر نیست.          | 400      |
| نام کاربری یا رمز عبور اشتباه است. | 400      |

## خروج (Logout)

```http
POST /api/uzi-token/auth/logout/
```

> **نیاز به احراز هویت: بله**

این درخواست بدنه ندارد.

### پاسخ موفقیت (200)

```json
{
  "message": "Logged out successfully."
}
```

### خطاها

| توضیحات                          | کد وضعیت |
|----------------------------------|----------|
| کاربر وارد حساب کاربری نشده است. | 401      |
