# هسته (Core)

اندپوینت‌های عمومی و زیرساختی پروژه.

## دریافت CSRF Token

```http
GET /api/uzi-token/csrf/
```

> **نیاز به احراز هویت: خیر**

این درخواست بدنه ندارد.

### پاسخ موفقیت (200)

| توضیحات        | نوع    | پارامتر      |
|----------------|--------|--------------|
| توکن CSRF      | String | `csrf_token` |

نمونه:

```json
{
  "csrf_token": "SOME_RANDOM_CSRF_TOKEN"
}
```

### نکات

- برای درخواست‌های ناامن (`POST`، `PUT`، `PATCH`، `DELETE`) که با سشن واردشده انجام می‌شوند، توکن دریافتی را در هدر `X-CSRFToken` ارسال کنید.
- درخواست‌های امن (`GET`، `HEAD`، `OPTIONS`) به این توکن نیاز ندارند.
- این اندپوینت برای کاربر واردشده و واردنشده قابل استفاده است.

## تنظیم زبان

```http
POST /api/uzi-token/set-language/
```

> **نیاز به احراز هویت: خیر**

### بدنه درخواست

| توضیحات | اجباری | نوع    | پارامتر |
|---------|--------|--------|---------|
| کد زبان | بله    | String | `code`  |

مقادیر مجاز: `fa` و `en`

نمونه:

```json
{
  "code": "en"
}
```

### پاسخ موفقیت (200)

| توضیحات      | نوع    | پارامتر   |
|--------------|--------|-----------|
| پیام موفقیت  | String | `message` |

نمونه:

```json
{
  "message": "Language changed to en"
}
```

### نکات

- زبان انتخاب شده در یک کوکی ذخیره می‌شود و در درخواست‌های بعدی اعمال می‌شود.
- زبان پیش‌فرض فارسی است.
